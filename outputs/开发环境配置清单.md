## 二、必须安装（按这个顺序做，别跳步）

### 第 1 步：WSL2（Windows 的 Linux 子系统）

**为什么要装**：Docker 在 Windows 上必须依赖 WSL2 才能运行，我们需要 Docker 来跑数据库和缓存。

**怎么做**

1. 点开始菜单，搜索 `PowerShell`，右键选择"以管理员身份运行"。
2. 执行：

```powershell
wsl --install
```

3. **重启电脑**（必须重启，否则不生效）。
4. 重启后打开 PowerShell，验证：

```powershell
wsl -l -v
```

看到有一个 `Ubuntu` 且 STATE 为 `Running` 即成功。

**如果报错**：提示"虚拟化未启用"，需要进 BIOS 开启 Intel VT-x / AMD-V（开机按 F2/Del 进入 BIOS，找 Virtualization Technology 打开）。

---

### 第 2 步：Docker Desktop

**为什么要装**：用它一键运行 MySQL（数据库）和 Redis（缓存），不需要在本机手动安装和配置这两个软件，卸载也干净。

**怎么做**

1. 打开 https://www.docker.com/products/docker-desktop/ ，下载 Windows 版安装包。
2. 安装时保持勾选 **Use WSL 2 instead of Hyper-V**。
3. 安装完成后启动 Docker Desktop，首次启动会要求登录，可以跳过或用邮箱注册。
4. 等左下角图标变成绿色（Engine running），在 PowerShell 验证：

```powershell
docker -v
docker run hello-world
```

能看到输出 `Hello from Docker!` 即成功。

**国内网络提示**：如果拉取镜像很慢，在 Docker Desktop 的 Settings → Docker Engine 里配置国内镜像加速地址。

**注意**：Docker Desktop 每次开机需要手动启动（或设置开机自启），不启动的话数据库连不上。

---

### 第 3 步：拉取 MySQL 与 Redis（一条命令搞定）

**为什么要做**：项目需要一个数据库存订单、一个缓存管库存和队列，用 Docker 拉起即可，不用装。

在项目根目录创建 `infra/docker/docker-compose.dev.yml`，内容如下：

```yaml
services:
  mysql:
    image: mysql:8.0
    container_name: hc-mysql
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: root123456
      MYSQL_DATABASE: home_cleaning
      TZ: Asia/Shanghai
    ports:
      - "3306:3306"
    command: --default-authentication-plugin=mysql_native_password --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci
    volumes:
      - mysql_data:/var/lib/mysql

  redis:
    image: redis:7-alpine
    container_name: hc-redis
    restart: unless-stopped
    ports:
      - "6379:6379"
    command: redis-server --appendonly yes
    volumes:
      - redis_data:/data

volumes:
  mysql_data:
  redis_data:
```

启动 / 停止命令：

```powershell
docker compose -f infra/docker/docker-compose.dev.yml up -d    # 启动
docker compose -f infra/docker/docker-compose.dev.yml down     # 停止（数据保留）
docker ps                                                      # 查看运行状态
```

启动后，本机就能通过 `localhost:3306` 和 `localhost:6379` 连接。

**端口冲突**：如果提示 3306 或 6379 被占用，说明本机已装过 MySQL/Redis，改 compose 文件里的映射端口（如 `"13306:3306"`）即可。

### 第 4 步：微信开发者工具（最重要）

**为什么要装**：这是开发、调试、预览、上传微信小程序的**唯一官方工具**，没有替代方案。

**怎么做**

1. 打开微信官方文档下载页：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 下载 **Windows 64 稳定版（Stable Build）**，不要下 Beta。
3. 安装后启动，用**微信扫码登录**。
4. 首次使用建议：新建项目 → 选择"测试号"（不需要 AppID 就能开发调试）。

**关键说明**

- 开发阶段用**测试号**即可，不需要等企业资质。等要接真实微信支付时才需要正式 AppID。
- 正式 AppID 需要在微信公众平台注册小程序账号后获取（属于"手续"部分，可以先跳过）。
- 工具内置模拟器，可以模拟定位、网络、机型，调试很方便。

### 第 6 步：数据库客户端（DBeaver）

**为什么要装**：直接查看和修改数据库里的订单数据，开发调试必备。没有它排查问题会非常痛苦。

**怎么做**

1. 下载 DBeaver Community（免费）：https://dbeaver.io/download/
2. 安装后新建连接 → 选择 MySQL → 填写：
   - 主机：`localhost`
   - 端口：`3306`
   - 数据库：`home_cleaning`
   - 用户名：`root`
   - 密码：`root123456`
3. 测试连接成功后保存。

**替代品**：Navicat（收费，中文界面友好）、MySQL Workbench（免费，功能偏基础）。

---

### 第 7 步：接口调试工具（Apifox）

**为什么要装**：后端写完接口要单独测试，不用每次都在小程序里点。

**怎么做**：下载 Apifox（中文，免费，支持导入 Swagger 文档）：https://apifox.com/

替代品：Postman、Hoppscotch。

## 四、环境自检脚本

装完后，把下面内容保存为 `check-env.ps1`，右键"使用 PowerShell 运行"，会逐项告诉你是否就绪：

```powershell
$items = @(
  @{ Name = 'Node.js';       Cmd = 'node -v' },
  @{ Name = 'pnpm';          Cmd = 'pnpm -v' },
  @{ Name = 'Git';           Cmd = 'git --version' },
  @{ Name = 'Docker';        Cmd = 'docker -v' },
  @{ Name = 'Docker 引擎';   Cmd = 'docker info --format "{{.ServerVersion}}"' },
  @{ Name = 'WSL2';          Cmd = 'wsl -l -v' }
)
foreach ($i in $items) {
  $result = try { (& ([scriptblock]::Create($i.Cmd)) 2>&1 | Select-Object -First 1) -join '' } catch { $null }
  if ([string]::IsNullOrWhiteSpace($result)) { $result = '未安装' }
  Write-Host ("{0,-12} : {1}" -f $i.Name, $result)
}

Write-Host ""
Write-Host "--- 容器状态 ---"
docker ps --format "{{.Names}}  {{.Status}}" 2>$null

Write-Host ""
Write-Host "--- 微信开发者工具 ---"
$wxPaths = @(
  "C:\Program Files (x86)\Tencent\微信web开发者工具",
  "C:\Program Files\Tencent\微信web开发者工具"
)
$wx = $wxPaths | Where-Object { Test-Path $_ }
if ($wx) { Write-Host "已安装：$($wx[0])" } else { Write-Host "未检测到（如装在其它目录请忽略）" }
```

## 六、常见问题

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| `wsl --install` 报错 | 未开启 BIOS 虚拟化 | 进 BIOS 开启 VT-x / AMD-V |
| Docker Desktop 一直黄灯 | WSL2 未更新或未重启 | 重启电脑，执行 `wsl --update` |
| 拉镜像特别慢 | 网络问题 | 配置国内镜像加速 |
| 3306 端口被占用 | 本机已有 MySQL | 改用 13306 端口映射 |
| 微信开发者工具打不开项目 | 目录选错了 | 目录要选到包含 `app.json` 的那一层 |
| pnpm 命令找不到 | 未全局安装 | `npm i -g pnpm`，或启用 `corepack enable pnpm` |
| Node 版本相关报错 | 依赖与 Node 24 不兼容 | 用 nvm-windows 切到 Node 20 / 22 LTS |
| VS Code 终端执行 docker 无权限 | Docker Desktop 未启动 | 先启动 Docker Desktop |
